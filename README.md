# CodeAlpha Stock Trading Platform

## Project Description

Stock Trading Platform is a Java console-based application developed as part of the CodeAlpha Java Programming Internship.

The application simulates a basic stock trading environment where users can view available stocks, buy and sell stocks, manage their portfolio, and view transaction history.

## Features

- Display available stock market data
- Buy stocks
- Sell stocks
- Manage user portfolio
- Track cash balance
- View transaction history
- Check current stock holdings
- Menu-driven console interface
- Object-Oriented Programming implementation

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- HashMap
- Scanner
- Java Time API

## How to Run

1. Open the project folder in VS Code.
2. Make sure Java is installed on your computer.
3. Open `Main.java`.
4. Click the Run button.
5. Enter your name.
6. Enter your starting cash balance.
7. Use the menu to view market data, buy or sell stocks, view your portfolio, and check transaction history.

## Main Menu

The application provides the following options:

1. Display Market
2. Buy Stock
3. Sell Stock
4. View Portfolio
5. View Account
6. Transaction History
7. Exit

## Object-Oriented Design

The project uses multiple classes to organize the application:

- `Stock.java` manages stock information.
- `Portfolio.java` manages the user's stock holdings.
- `Transaction.java` stores transaction details.
- `User.java` manages user information and cash balance.
- `TradingPlatform.java` manages market operations and transactions.
- `Main.java` provides the main program and user interface.

## Output

The application displays:

- Available stocks and their prices
- Successful or unsuccessful buy/sell operations
- User cash balance
- Current stock holdings
- Transaction history
